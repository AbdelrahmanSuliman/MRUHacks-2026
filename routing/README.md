# Calgary cycling route exporter

Exports cycling directions from HeiGIT/openrouteservice using `cycling-regular`
and its JSON endpoint. The existing `requests` package is the only dependency;
no Unity SDK, geocoder, map tiles, or paid service is needed by this script.

## Run

1. Use Python 3 with `requests` installed (`python3 -m pip install requests` if needed).
2. Set `HEIGIT_API_KEY` privately in the terminal running the script. Do not put the
   key in this folder, JSON, screenshots, or version control.
3. Generate a route:

```bash
python3 route_export.py --start-lon -114.0631 --start-lat 51.0443 --end-lon -114.0680 --end-lat 51.0540 --output route.json
```

Each endpoint accepts a longitude/latitude pair in degrees. Longitude must be
finite and within [-180, 180]; latitude within [-90, 90]. A coordinate pair
replaces the corresponding preset. Valid geographic coordinates do not guarantee
cycling coverage: choose points near accessible roads or paths.

`python3 route_export.py` retains the Calgary Tower → Prince's Island Park presets.
Reverse with `python3 route_export.py --start island --end tower`.
Use `python3 route_export.py --help` for all options. The output parent directory
must exist. API/network, invalid response, and file errors return exit status 1;
invalid CLI input returns 2. Requests time out after 40 seconds and are not retried
automatically, conserving quota. A failed API request leaves existing output intact.

## Output and handoff

`route.json` contains requested endpoints (`longitude`, `latitude`), distance in
metres, estimated duration in seconds, encoded geometry, decoded coordinates,
and navigation steps. `coordinatesLonLat` is always **[longitude, latitude]**.
`coordinatesLatLng` is retained for compatibility and uses the opposite order;
new integrations should use `coordinatesLonLat`. No elevation is requested or invented.

Send `route.json` and `UNITY_HANDOFF.md` to Unity. The key is needed only to
regenerate data. See that handoff for parsing and Cesium positioning details.

## Tests

```bash
python3 -m unittest -v
```

Tests mock API responses and make no network calls. They cover decoding,
coordinate order/ranges, schema, argument validation, HTTP/network/JSON failures,
missing credentials, and output creation/preservation.

The current `route.json` was generated by a successful live request on 2026-10-24
for the coordinate command above: 65 points, 12 steps, 1,421.0 m / 320.4 s.
Validation confirmed encoded/decoded geometry agreement, longitude-first Calgary
coordinates, valid step indices, distance and duration. Visual alignment and terrain
heights still need checking in Unity.

If your terminal reports a missing key but you saved the export in `~/.zshrc`, run:

```bash
source ~/.zshrc
```

The saved export was verified to load in new interactive and login-interactive zsh
sessions. Existing terminals need to load it too. Do not print the key to verify it.
